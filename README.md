# homebrew-tap

```
brew uninstall --zap --cask logi-options+  # if previously installed
brew tap gohanlon/tap
brew install --cask offline-logi-options+
```

## Casks

**offline-logi-options+** — Cask for Logitech's offline Logi Options+ installer. Installs a version that runs without phoning home—your devices shouldn't depend on Logi's service availability.

## Maintenance

A daily workflow checks for upstream changes and opens a PR when updates are available.
